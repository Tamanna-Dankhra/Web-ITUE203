
# Student Hub Portal

## Project Description
Student Hub is a web-based portal for managing student
information, events, notices, registrations, and admin activities.

## Technologies Used
- HTML
- CSS and Bootstrap
- JavaScript
- PHP
- MySQL
- XAMPP
- GitHub

## Installation
1. Install XAMPP.
2. Copy the project folder into htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import the studenthub.sql database file.
6. Configure the database connection in the PHP file.
7. Open the project in your browser.

## Features
- User authentication
- Student management
- Event management
- AJAX CRUD operations
- Admin dashboard
- Role-based access control
- Responsive design

## Testing
Test login, logout, navigation, CRUD operations,
